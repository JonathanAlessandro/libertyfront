# Referência do site anterior

Os arquivos HTML, CSS, JavaScript e imagens anteriores foram preservados aqui. Eles não são usados pelo aplicativo React nem copiados para `dist/`.

As páginas mantidas estão em `src/pages/`, os estilos em `src/styles/` e os arquivos públicos em `public/`. Publique somente `dist/`, seguindo o README da raiz.

`migrate-reference.mjs` registra o conversor usado na migração; não faz parte dos comandos de desenvolvimento ou publicação.
